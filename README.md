# 土地評価計算アプリ

財産評価基本通達に基づき、宅地の相続税・贈与税評価額を計算するWebアプリです。
ビルドは不要で、ブラウザだけで動きます（入力内容はブラウザ内に保存され、外部には送信しません）。

## 使い方

```sh
npm start          # http://localhost:8000 を開く（python3 の簡易サーバー）
```

`index.html` をブラウザで直接開いても使えます。

## 対応している評価

| 区分 | 内容 |
| --- | --- |
| 評価方式 | 路線価方式／倍率方式（固定資産税評価額 × 倍率） |
| 路線加算 | 奥行価格補正、側方路線影響加算（角地・準角地、三方・四方路線、接道按分）、二方路線影響加算 |
| 画地補正 | 間口狭小・奥行長大補正、不整形地補正（想定整形地・かげ地割合から自動算定、下限0.60）、地積規模の大きな宅地（規模格差補正率）、がけ地補正 |
| 減額 | セットバックを必要とする宅地（×0.7控除） |
| 権利 | 自用地、貸宅地、貸家建付地、借地権、貸家建付借地権 |
| 特例 | 小規模宅地等の特例（特定居住用・特定事業用・貸付事業用） |

計算は「土地及び土地の上に存する権利の評価明細書」の順序（1 一路線 → 2〜4 路線加算 → 5 間口狭小・奥行長大／不整形地 → 6 地積規模 → 8 がけ地）で行い、各段階で円未満を切り捨てます。計算明細はそのまま印刷できます。

## 構成

```
index.html          画面
css/style.css       スタイル（ダークモード・印刷対応）
js/tables.js        調整率表（付表1〜8、規模格差補正率、借地権割合）
js/valuation.js     計算エンジン（ブラウザ・Node.js 両対応）
js/app.js           画面の入出力
test/               計算エンジンのテスト（node --test）
```

```sh
npm test
```

## 注意事項

- 補正率は平成30年1月分以降用の調整率表に基づき、`js/tables.js` にまとめています。申告に使う前に、国税庁が公表する最新の調整率表と照合してください。
- 無道路地、容積率の異なる2以上の地域にわたる宅地、私道、土砂災害特別警戒区域内の宅地などには対応していません。
- 地積規模の大きな宅地は、地区区分と地積のみ自動で判定します。市街化調整区域・工業専用地域・容積率の要件はご自身で確認してください。
- 本アプリは概算用です。最終的な判断は税理士等の専門家にご相談ください。
